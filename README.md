# Infinite Improbability Drive

Adds several equipment items based off of the Infinite Improbability Drive from The Hitchhiker's Guide to the Galaxy

> [!WARNING]
> HevLib is required for this mod to function.
> A download can be found from its [releases page](https://github.com/rwqfsfasxc100/HevLib/releases/latest)

## Additions

**Finite Probability Drive**:
- Randomly teleports you to a random location when traveling to a POI.
- Cost: 7,500,000 E$

**Infinite Probability Drive**
- Adds a persistent POI that when traveling to, sends you to a random position in the rings.
- Cost: 25,000,000 E$
